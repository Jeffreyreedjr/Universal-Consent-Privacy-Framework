# Plugin branding assets (shipped in the zip)

Copies of the WordPress.org icons/banner used inside the installed plugin (admin menu icon, docs). Keep in sync with [`.wordpress-org/`](../../.wordpress-org/) when artwork changes.

| File | Use |
|------|-----|
| `icon-128x128.png` | WP admin menu icon |
| `icon-256x256.png` | High-res brand mark |
| `banner-772x250.png` | Compact banner (README / marketing) |

Full directory set (retina banner + screenshots) stays in `.wordpress-org/` for SVN / GitHub only — not packed into the plugin zip.
